# Machine Learning Poisoning Analysis

## Overview
This project analyzes the impact of data poisoning attacks on different machine learning models and compares their performance on clean and poisoned datasets.

## Models Used
- Logistic Regression
- Random Forest
- Naïve Bayes
- Decision Tree
- SVM

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score

## Project Structure

│
├── data/

├── results/
└── images/
## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Goal
The goal of this project is to understand how poisoned data affects machine learning model performance and robustness.
